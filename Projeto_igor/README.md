# Sistema de Gerenciamento de Treinos

## Sobre o projeto
Sistema web desenvolvido com Python, Flask, Jinja2 e SQLite3 para gerenciar treinos e exercícios físicos.

## Funcionalidades
- Cadastro de usuários.
- Login e logout.
- Senhas protegidas por hash.
- Cadastro, listagem e exclusão de treinos.
- Cadastro, listagem e exclusão de exercícios.
- Proteção de páginas por sessão.
- Utilização de cookies.

## Tecnologias utilizadas
- Python
- Flask
- Jinja2
- SQLite3
- HTML e CSS

## Como executar

1. Instale as dependências:

   `pip install -r requirements.txt`

2. Inicialize o banco de dados:

   `python iniciar_bd.py`

3. Execute o sistema:

   `python run.py`

4. Acesse no navegador:

   `http://127.0.0.1:5000`
